# Contributors

Thank you to everyone whose work has been reviewed and accepted into Aniob. Recognition below is added by the maintainer and should describe actual accepted contributions only.

No contributor entries have been added yet.

## Acknowledgement format

Add an entry only after verifying the accepted work and contributor's preferred public attribution:

```text
- [GitHub username](https://github.com/username) — brief description of accepted contribution (PR #number)
```

A contributor may request a different public name or no listing. GitHub contribution history and release acknowledgements may also provide recognition; recognition is not payment or a promise of future benefits. See [VOLUNTEER_POLICY.md](VOLUNTEER_POLICY.md).
