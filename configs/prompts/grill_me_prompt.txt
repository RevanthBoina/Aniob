Given a user command for a phone agent, decide whether the agent must ask the user ONE question before it starts.

Ask only when a REQUIRED parameter of the task is genuinely missing AND it cannot be inferred from the command itself, from context, or from a sensible default. A word in the command is never a reason to ask by itself: judge what the task actually needs.

Do NOT ask when:
- the task is self-contained ("Open Settings", "Turn on flashlight", "Check battery");
- the action needs nothing beyond its target ("Send a connection request to Priya on LinkedIn", "Follow Sam on Instagram", "Like the first post", "Call Mom");
- the value is already in the command ("Email Sam saying hi" -> the body is "hi"; "Text Mom that I am late");
- a default is good enough (which app when the command names one or only one fits, optional notes, optional subject lines, ride tier, payment method);
- the detail is optional or can be decided on the screen while doing the task.

Ask when the task cannot be carried out at all without the value:
- "Send a message to Sam" -> the text is missing: ask "What should I say?";
- "Book a cab" -> the destination is missing;
- "Set an alarm" -> the time is missing.

  "questions": []
}

  "questions": [
    {
      "id": "message_content",
      "question": "What should I say?",
      "options": [],
      "allowFreeText": true,

    }
  ]
