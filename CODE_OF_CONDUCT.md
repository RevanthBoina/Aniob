# Code of Conduct

Aniob welcomes students, volunteers, maintainers, and first-time contributors. We want a respectful, practical space where people can learn and collaborate regardless of experience, identity, background, or communication style.

## Expected behavior

- Be kind, patient, and constructive. Critique code and ideas, not people.
- Explain disagreements respectfully and welcome good-faith questions.
- Keep comments relevant, inclusive, and focused on the project.
- Respect privacy. Do not publish another person's contact details, private messages, credentials, or device data without permission.
- Follow the repository's security disclosure instructions; do not post vulnerabilities or secrets publicly.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized conduct, doxxing, intimidation, repeated disruptive behavior, or publishing private information without consent are not acceptable. Spam, credential theft, or deliberately unsafe submissions are also not acceptable.

## Reporting and response

Report conduct concerns privately to the founder/maintainer, [Revanth Boina](https://github.com/RevanthBoina), via GitHub. For a security issue, use the private reporting steps in [SECURITY.md](SECURITY.md), not a public issue. The maintainer will review reports, protect privacy as reasonably possible, and take proportionate action, which may include a warning, request to edit/remove content, temporary pause, or exclusion from project spaces. Retaliation against a good-faith reporter is not acceptable.

This code applies to Aniob project spaces and project-related interactions. If you are unsure how to handle a situation, ask the maintainer privately.
