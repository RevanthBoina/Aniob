# Student contributor quick start

Welcome to Aniob! This is a simple, fork-and-PR project. You do not need to fill out a long application, share identity documents, or request write access.

## Your first contribution

1. Read the short [contribution guide](../CONTRIBUTING.md).
2. Choose an open issue that interests you. Comment: “I’d like to work on this.” If nobody has replied yet, wait briefly before starting so we can avoid duplicate work.
3. Fork the repository, create a branch in your fork, and make a focused change.
4. Run the relevant tests/checks and open a pull request to `main`.
5. The founder reviews it, may suggest changes, and decides whether to accept and merge it.

You can start by helping with a bug, test, documentation improvement, accessibility issue, UI polish, Android integration, or agent-core task. Ask a question on the issue if its scope is unclear. Small first PRs are encouraged.

## Optional contributor details

Only share contact details if they are useful for coordination or recognition. Do not post them publicly in an issue or PR without thinking about visibility. GitHub username is enough for normal contribution credit.

```text
Full name:             [optional]
GitHub username:       [required for attribution; link is fine]
Email:                 [optional]
Area of interest:      [optional]
```

Never provide Aadhaar, PAN, passwords, private keys, bank/payment details, or other sensitive personal information. This template is not an application or contract. Any separate contribution agreement, if needed for a contribution, is handled transparently and separately by the founder; do not sign anything you do not understand.
